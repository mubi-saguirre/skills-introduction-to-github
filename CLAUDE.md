# CLAUDE.md

Guidance for Claude Code when working in this repository.

## What this repo is

A completed copy of GitHub Skills' **"Introduction to GitHub"** exercise, owned by `mubi-saguirre` and shared with MUBI teammates as a sandbox for learning GitHub basics: branches, commits, pull requests and merging. There is no application code, build step or test suite.

## Layout

- `README.md` – the exercise's "Congratulations" page, generated by the exercise tooling. Don't rewrite it unless asked.
- `PROFILE.md` – the file created during the exercise (step 2). Safe to edit for practice.
- `.github/steps/` – instructions for each exercise step (Markdown).
- `.github/workflows/` – the exercise's GitHub Actions workflows (`0-start-exercise.yml` to `4-merge-your-pull-request.yml`).
- `.github/images/` – screenshots used by the step instructions.

## Important: exercise workflows

All five workflows are **disabled** now that the exercise is finished. Do not re-enable them: `Step 0` runs on every push to `main` and would restart the exercise, overwriting `README.md` and opening a new issue.

## Working conventions

- Practice the GitHub flow: create a branch, commit, open a pull request, then merge. Avoid committing straight to `main` except for small housekeeping changes.
- Use short, descriptive commit messages in the imperative ("Add X", "Fix Y").
- Collaborators have write access, so check `git pull` before starting work to avoid conflicts.
